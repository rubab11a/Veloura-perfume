# VELOURA — Luxury Perfume Website

A responsive, multi-page luxury fragrance storefront built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home page and featured collection
- `shop.html` — Product collection with search, category/price filters and sorting
- `product.html` — Product details, fragrance notes, quantity selector and add-to-bag
- `cart.html` — Shopping bag, quantity controls, remove items and order summary
- `about.html` — Brand story and values
- `contact.html` — Contact details and demo contact form

## Run locally
1. Extract the project folder.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server (recommended).
4. Navigate between pages using the site navigation.

## Features
- Responsive layout for desktop, tablet and mobile
- Shared luxury visual theme and navigation
- Product cards and detail pages linked by product IDs
- Shop search, category filters, price filters and sorting
- Cart saved in browser `localStorage`
- Quantity controls and subtotal/shipping calculation
- Demo contact and newsletter forms with user feedback

## Notes
- Product photography and Google Fonts are loaded from external URLs, so internet access is required for those assets.
- This is a front-end demo. It does not process real payments or send contact/newsletter messages to a live service.
- Product prices and descriptions are sample content for the demo.
